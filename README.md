# ZEEAYB — Developer Portfolio

A personal portfolio for Zubaidah Shuayb, a full-stack developer and independent product builder working under the ZEEAYB identity.

The site presents selected work, technical capabilities, services, background, and contact channels through a custom dark interface with pink and lavender accents.

## Overview

The portfolio is organized into focused sections:

- **Home** — introduction and engineering focus
- **About** — professional background and development philosophy
- **Services** — software and product development services
- **Projects** — selected product and platform case studies
- **Skills** — frontend, backend, data, and engineering tools
- **Analytics** — portfolio analytics section
- **Contact** — professional contact channels

## Run locally

Requirements: Node.js and npm.

```bash
git clone https://github.com/zubaidah-shuayb/Zeeportfolio.git
cd Zeeportfolio
npm install
npm run dev
```

Vite will print the local development URL in the terminal.

## Available scripts

| Command | Description |
| --- | --- |
| `npm run dev` | Start the local development server |
| `npm run build` | Create a production build |
| `npm run preview` | Preview the production build |
| `npm run lint` | Run ESLint |
